Go Live Guide

How this page becomes a public website where the link works for everyone

The big picture

This page (index.html)→GitHub repository→Vercel deploy→Public link — works for everyone

Right now this page runs inside Muse, so its link only opens here. The survey link is already built in — the moment this same page is hosted on Vercel, the link becomes a real public address that anyone can open on any phone or computer. Nothing in the page needs to change: the link is generated from your website address plus the survey code — your Vercel address followed by ?s=SRV-001.

① Download this page

  1. Click the button below — it saves this exact page as index.html on your device.
  2. Keep the file name exactly index.html — browsers and Vercel look for that name first.

② Put it on GitHub

  1. Go to github.com → sign up / log in → New repository.
  2. Name it e.g. ai-survey-software, keep it Public, create it.
  3. Click uploading an existing file, add your index.html, then Commit changes.

③ Deploy with Vercel

  1. Go to vercel.com → Sign up with GitHub.
  2. Add New → Project → import your ai-survey-software repository.
  3. No settings to change — just click Deploy.
  4. In about a minute Vercel gives your public address, e.g. ai-survey-software.vercel.app.

④ Share the survey link

  1. Your survey link is your Vercel address + the survey code: ai-survey-software.vercel.app/?s=SRV-001
  2. Paste your Vercel address into the “Your live website address” box on the Home page — the link shown there and the QR code update to your real public link, ready to copy and share.
  3. Share it anywhere: WhatsApp, Messenger, class group, or printed QR. Anyone opening it lands directly on the form.

What works after going live

  • ✅ The link opens the survey form directly for everyone, on mobile and computer — no app needed.
  • ✅ The AI Generator, editor and Admin Dashboard all run in the browser, exactly as here.
  • ✅ Free forever on GitHub + Vercel for a page like this.

✅ GitHub-e push dewar age — last checklist

  1. Download index.html button diye file-ta download koro — ei ektai file, ar kono code change lagbe na.
  2. File-er naam jeno thik index.html thake — naam bodlabena.
  3. GitHub-e notun Public repo baniye file-ta upload kore Commit koro.
  4. Vercel-e oi repo import kore Deploy koro — kono setting bodlate hobe na.
  5. Deploy hole Vercel ekta asol address debe — seta Home page-er ghore boshao, tahole sob Copy Link oi address diye hobe.
  6. Sesh check: onno ekta phone theke survey link-ta khule dekho — shudhu form ashbe, 404 ashbe na.

One honest limitation

  • Answers now collect in one shared Admin through the free Vercel KV backend — connect it in the Vercel dashboard under Storage → KV. No Telegram, no other account.
  • If the backend is not connected yet, answers are stored on the visitor's own device only — the Admin badge will say “Shared backend: OFF”.
  • For the assignment demo, submit a few test answers yourself and show them live in the Dashboard.
